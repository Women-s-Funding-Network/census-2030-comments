2030 Census Rule: Public Comment Explorer

Search every public comment on the Census Bureau's proposed rule on who is counted in 2030 and what the census asks. Compiled by Women's Funding Network for member funds and partners.

Try: "biological sex" maternal "tax records" undocumented "women and girls" nonbinary

Searches every comment, including form letters, which are listed once with the number of copies sent. Use quotes for an exact phrase. Results open in Datasette, a free data explorer; the first search takes about 30 seconds to load the database (19 MB), then it's quick.

About timing. Comments appear on Regulations.gov after Census Bureau review, usually 1 to 5 days after they are submitted, and comments with offensive or threatening language are not posted. This site is updated periodically, so the most recent days are incomplete and totals here will run below the number of comments actually submitted.

About this data

Privacy. Individual commenters are not named: names, signatures, addresses, ZIP codes, emails and phone numbers are removed automatically, and individuals' attachments are not included. Organizations and public officials are named. Every comment links to the original on Regulations.gov. Redaction is automated, so if you spot a name that slipped through, please let us know.

Method. Position (oppose, support, unclear) and topics are assigned by keyword rules, so treat them as approximate. State is inferred from the comment text where a commenter names it. Form letters are identical or near-identical letters sent three or more times; their shared text is stored once.
